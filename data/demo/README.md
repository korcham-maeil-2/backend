## 공고 파일 형식

공고마다 같은 내용을 여러 형식으로 만든다. 입력 노드(`read_image` / `read_pdf` / `read_sheet`)가 형식과 관계없이 같은 값을 뽑는지 확인하는 용도다.

| 파일 | 설명 |
|---|---|
| `{id}_text.pdf` | 글자를 복사할 수 있는 PDF → PyMuPDF 텍스트 추출 경로 |
| `{id}_image.pdf` | 글자를 복사할 수 없는 PDF (페이지가 이미지) → 이미지 인식 경로로 넘어가야 함 |
| `{id}.png` | 채용 사이트 캡처처럼 보이는 이미지 |
| `{id}.xlsx` | 엑셀 (`항목`/`내용` 2열). xlsx는 내부가 유니코드라 인코딩 구분 없음 |
| `{id}_utf8.csv` | CSV, UTF-8 (BOM 없음 — 엑셀에서 바로 열면 한글이 깨질 수 있음) |
| `{id}_euckr.csv` | CSV, EUC-KR — UTF-8로 읽으면 실패하므로 인코딩 판별이 필요 |
| `source.json` | 생성에 쓴 원문 항목 |
| `expected.json` | **정답**: 정규화 노드가 뽑아야 하는 값 (테스트 기댓값) |

### 울산 시나리오 파일 (실제 사용자가 올릴 법한 모양)

위 표처럼 한 내용을 여러 형식으로 찍어 내는 대신, 사용자가 실제로 들고 올 파일 모양을 하나씩 만들었다. 표 밖의 잡음 속에서 값을 찾는 경우를 확인하는 용도다.

| 파일 | 설명 |
|---|---|
| `postings/up_seoul/up_seoul_offer_mail.png` | 합격 안내 메일 캡처. 메일 목록·서명·첨부 칩 사이에서 처우 표만 읽어야 함 |
| `postings/stay_ulsan/stay_ulsan_text.pdf` | 디자인된 1쪽 공고. 통근버스 노선도는 그림이라 텍스트로 안 나옴 |
| `postings/stay_ulsan/stay_ulsan_image.pdf`, `stay_ulsan.png` | 같은 공고의 이미지 PDF와 캡처 |
| `postings/across_gwangju/source.json` | 파일 없이 채팅으로 들어오는 텍스트 (인사팀 문자 + 사용자 설명) |
| `users/user_c/payslip_2026-10.png` | 모바일 급여명세서 캡처. 연장근로수당·식대 비과세·공제 내역 포함 |
| `users/user_c/spending_2026-08_10.xlsx` | 가계부 앱 내보내기 211건. 카드대금 중복, 분류 없는 월세 이체, 명절상여가 섞여 있음 |

이 파일들은 손으로 디자인해 만들었고 생성기가 없다. 정답은 공고 폴더의 `expected.json`, 사용자 파일은 `users/user_c.json`의 `expected_from_files`에 있다.
메일·공고 연락처는 `.example` 도메인이다.

## 다시 만들기

`scripts/build_demo_postings.py`에서 내용을 고친 뒤 backend 폴더에서 실행한다 (macOS + Google Chrome 필요).
`expected.json`은 손으로 쓴 파일이라 덮어쓰지 않는다. 내용을 바꾸면 함께 고친다.

```bash
uv run --no-project --with openpyxl --with pymupdf python scripts/build_demo_postings.py
```
