## 공고 파일 형식

공고마다 같은 내용을 여러 형식으로 만든다. 입력 노드(`read_image` / `read_pdf` / `read_sheet`)가 형식과 관계없이 같은 값을 뽑는지 확인하는 용도다.

| 파일 | 설명 |
|---|---|
| `{id}_text.pdf` | 글자를 복사할 수 있는 PDF → PyMuPDF 텍스트 추출 경로 |
| `{id}_image.pdf` | 글자를 복사할 수 없는 PDF (페이지가 이미지) → 이미지 인식 경로로 넘어가야 함 |
| `{id}.png` | 채용 사이트 캡처처럼 보이는 이미지 |
| `{id}.xlsx` | 엑셀 (`항목`/`내용` 2열). xlsx는 내부가 유니코드라 인코딩 구분 없음 |
| `{id}_utf8.csv` | CSV, UTF-8 (BOM 없음 — 엑셀에서 바로 열면 한글이 깨질 수 있음) |
| `{id}_euckr.csv` | CSV, EUC-KR — UTF-8로 읽으면 실패하므로 인코딩 판별이 필요 |
| `source.json` | 생성에 쓴 원문 항목 |
| `expected.json` | **정답**: 정규화 노드가 뽑아야 하는 값 (테스트 기댓값) |

## 다시 만들기

`scripts/build_demo_postings.py`에서 내용을 고친 뒤 backend 폴더에서 실행한다 (macOS + Google Chrome 필요).
`expected.json`은 손으로 쓴 파일이라 덮어쓰지 않는다. 내용을 바꾸면 함께 고친다.

```bash
uv run --no-project --with openpyxl --with pymupdf python scripts/build_demo_postings.py
```
